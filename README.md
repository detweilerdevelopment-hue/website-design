# Regional Mortgage Alliance website

A responsive nonprofit mortgage-industry association website, created from an empty workspace. The organization name is provisional. The written nonprofit request takes precedence over the attached production-studio brief.

## Run

`npm install` then `npm run dev`. Production build: `npm run build`.

## Before launch

Replace the provisional identity and footer concept notice with the real organization name and service area. Add confirmed event details and contact information. Connect the inquiry forms to the organization's approved backend, supply a privacy policy, and replace the preview messaging. Currently forms generate a local text-file download and do not submit information or claim successful delivery.

Photos: Unsplash, downloaded into `public/images`. Fonts: Google Fonts (DM Sans and Libre Caslon Display). No membership statistics, endorsements, partners, or event dates are fabricated.
